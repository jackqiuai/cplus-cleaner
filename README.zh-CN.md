# CPlus Cleaner — Windows Disk Cleaner & App Mover｜C盘清理与软件搬家

**清理磁盘、搬移软件、整理聊天缓存，在支持简体中文、繁体中文和英文的桌面界面中管理存储空间。**

**简体中文** · [繁體中文](README.zh-TW.md) · [English](README.md) · [问题反馈](https://github.com/jackqiuai/cplus-cleaner/issues) · [参与贡献](CONTRIBUTING.md) · [MIT 许可证](LICENSE)

CPlus Cleaner 是 Windows 桌面清理与空间管理工具，提供 C盘清理、软件搬家、软件压缩、聊天清理、隐私清理、大文件搬家、重复文件清理、软件卸载、弹窗拦截与系统瘦身。

**绿色版本，无需安装。** 下载 EXE 即可直接运行，也可解压便携 ZIP 后启动 `CPlusCleaner.exe`，无需另行安装 Python。

**项目状态：** 已包含完整 Python 源码、图片、清理规则及语言资源，并配置 [GitHub Actions 自动构建 Windows x64 EXE](https://github.com/jackqiuai/cplus-cleaner/actions/workflows/build-windows.yml)。构建成功后可下载产物，发布 GitHub Release 时会自动附加 EXE、便携 ZIP 和校验文件，详见[构建说明](docs/BUILDING.md)。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 首页扫描 | 按勾选的功能依次扫描，显示进度、容量或条数；打开功能页时复用本轮结果。 |
| C盘清理 | 按类型汇总临时文件、缓存、日志及已支持的应用残留。默认扫描全部时间，可选择7天内、30天内、180天内。实际扫描 Windows 系统所在分区。 |
| 聊天清理 | 支持微信、QQ、WhatsApp、Telegram、Discord、Slack、Microsoft Teams、Signal 的已知缓存或附件目录。具体覆盖取决于客户端版本和数据布局。 |
| 大文件搬家 | 按文件类型扫描大于30 MiB的文件；展开类别后可对类别或单个文件搬家、删除。 |
| 软件搬家 | 将符合条件的软件搬到另一 NTFS 分区，复制后校验内容，并使用目录联接保留原路径。含系统服务的软件不列入。 |
| 软件压缩 | 调用 Windows 透明压缩能力处理符合条件的安装目录，可通过记录还原受支持的文件；排除受保护的软件。 |
| 重复文件清理 | 使用 SHA-256 比较完整内容，每组至少保留一份。 |
| 隐私清理 | 分类整理已支持的 Windows 使用痕迹、软件痕迹、Chrome/Edge 浏览和下载历史及派生隐私项目。 |
| 软件卸载 | 搜索、选择单个或多个已安装软件，调用其注册的发布者卸载程序；卸载后可检查受支持的残留。 |
| 弹窗拦截 | 识别已支持的软件，按组或单条规则设置拦截；列表不展示暂不支持的规则。 |
| 系统瘦身 | 查看系统文件占用，管理回收站、休眠、虚拟内存及 Windows 组件存储。 |

设置支持每日定时清理、开机自启动、关闭时隐藏到系统托盘和语言选择。操作记录使用独立窗口。

## 运行要求

- Windows 桌面环境，面向 Windows 10 / Windows 11。
- 从源码运行时需要 Python 3.10 或以上及 Tkinter；自动 EXE 构建和回归测试使用 Python 3.13。
- 运行时不需要额外安装第三方 Python 包。
- 软件搬家要求源、目标位于不同 NTFS 分区；软件压缩要求 NTFS 支持。
- 部分受保护目录及系统维护操作需要管理员权限；只读组件分析可请求 Windows UAC 授权。

## 从源码启动

请保留包含 `app.py`、`start.bat`、`cplus_cleaner/`、`assets/`、`rules/`、`locales/` 的**完整源码目录**，资源位置和发布检查见[源码目录说明](docs/SOURCE_LAYOUT.md)。

源码文件夹可命名为 `CPLUSCLEANER`。启动脚本和运行资源都相对于项目目录定位，改名无需修改代码。设置、日志和恢复记录统一保存在 `%LOCALAPPDATA%\CPLUSCLEANER\`。

1. 安装 Python，保留 **Tcl/Tk and IDLE** 组件。
2. 克隆本仓库或下载源码 ZIP，打开 `app.py` 所在目录。
3. 双击 `start.bat`，或执行：

```powershell
python app.py
```

重复启动会唤起已有窗口，不会打开多个实例。更新源码后，应先完全退出旧进程，再启动新版本。

可以先执行以下命令核对源码和运行资源完整性；该检查不会扫描或处理用户文件：

```powershell
python tools/verify_source_tree.py
```


Python 源码按功能整理到 `cplus_cleaner/`，根目录仅保留 `app.py`。每个文件的用途见 [Python 模块说明](docs/MODULES.md)，图片和规则用途见[资源说明](assets/README.md)。

## 基本使用

1. 在首页勾选需要的功能并点击“扫描”，也可进入对应功能页单独扫描。
2. 查看各类型的占用或记录数量，检查默认勾选。
3. 取消不需要处理的项目，再执行“立即清理”“立即搬家”“压缩”或“卸载”。
4. 查看操作结果和操作记录；软件搬家、软件压缩另有专用恢复记录。

C盘和聊天清理按类型汇总，不逐个展示文件。大文件搬家与重复文件清理支持单个文件操作。

## 软件压缩使用经验

一次实际使用中，某软件的磁盘占用从 **13.2GB** 降到 **9.1GB**，节省约 **4.1GB**。这是单次使用结果，不能保证其他软件获得相同收益。体积较大的软件可能节省更多绝对容量，但压缩率不一定更高，实际效果取决于文件内容。

本次使用中，压缩后软件的启动速度明显变慢。**一般情况下，不建议将软件压缩作为常规操作**，尤其是经常使用或重视启动速度的软件。

**若其他分区有可用空间，优先使用软件搬家，再考虑软件压缩。** 软件搬家可释放原分区空间，但不会减少软件在所有磁盘上的合计占用；软件压缩则是在减少占用与性能影响之间取舍。需要撤销压缩时，可在“软件压缩 → 压缩记录”中还原。

部分文件可能维持未压缩状态，程序会跳过且不自动重试。仅发生这类跳过仍计为压缩完成，压缩记录中的操作为“还原”。

## 常见问题

<details>
<summary>为什么点击 × 后，软件还在运行？</summary>

启用“设置 → 点击关闭时隐藏到系统托盘”后，× 会隐藏主窗口，程序仍继续运行。要完全退出，请在右上角三横菜单中选择“退出软件”，或右键托盘图标退出；请先等待正在执行的操作完成。

</details>

<details>
<summary>为什么部分软件没有出现在搬家或压缩列表中，或者暂时无法操作？</summary>

软件搬家只考虑 Windows 系统盘上符合条件的安装目录，并排除含系统服务的软件。系统目录、共享组件以及不支持的链接目录或无法读取的路径也会排除。软件压缩排除受保护的软件，并要求 NTFS 分区。软件仍在运行或权限不足时，操作可能暂时不可用，请查看对应条目的状态说明。

</details>

<details>
<summary>软件搬家后，为什么原来的文件夹还在？</summary>

软件搬家会在原路径建立指向目标文件夹的 Windows 目录联接，让原路径保持可访问。需要迁回时，请使用“软件搬家 → 搬家记录”还原受支持的记录；软件仍在使用目标文件时，应保留这些文件。

</details>

<details>
<summary>为什么实际释放的空间与扫描容量不同？</summary>

清理和大文件扫描主要统计文件逻辑大小。实际释放空间还取决于磁盘分配情况及哪些文件能够处理；已变化、被占用或无法访问的文件可能跳过。软件搬家与压缩候选容量单独统计，不计入普通垃圾总量。

</details>

<details>
<summary>完全退出软件后，定时清理还会执行吗？</summary>

软件需要保持运行或驻留系统托盘。到达设定时间后，会重新扫描全部时间范围的 C盘常规垃圾，再清理默认常规分类，不会依次执行所有功能。软件忙碌时任务会延后；完全退出进程后不执行定时清理。

</details>

## 使用前需要了解

- **清理操作会永久删除所选文件，不经过回收站。** 请先扫描并检查选项。
- 聊天清理完成后，默认勾选有容量的已支持分类；微信/QQ 的部分分类包含接收文件和图片、视频等附件，不能全部视为无用缓存。
- 隐私清理可删除所选历史条目，不会据此删除对应的下载文件，也不保证擦除所有活动痕迹。
- 定时清理会先重新扫描全部时间范围的 C盘常规垃圾，再删除默认常规分类；软件必须运行或驻留托盘，完全退出后不执行。
- 虚拟内存、休眠、回收站和组件存储单独管理，不混入普通垃圾容量。
- 操作前会重新检查已支持的路径和文件身份。文件变化、权限不足、客户端仍在运行或数据布局不支持时，可能跳过对应项目。
- 容量主要按文件逻辑大小统计，不保证与磁盘实际释放空间相等。软件搬家、压缩容量不计入首页普通垃圾总量。
- 恢复记录不是文件内容备份；软件更新、目录替换或操作后的新数据会影响自动还原。

## 还原已搬家或压缩的软件

还原前请先关闭对应软件，并确保磁盘有足够空间存放还原后的数据。

1. **软件搬家：** 打开“软件搬家 → 搬家记录”，选中对应记录，点击“还原选中软件”。程序会将目标目录中的当前数据复制并校验回原位置，用还原后的文件夹替换目录联接，同时保留目标副本。自动还原要求有效的本机记录，且原目录联接与目标目录的对应关系未变化。
2. **软件压缩：** 打开“软件压缩 → 压缩记录”，点击对应条目的“还原”。程序会解压记录中仍通过路径与文件身份检查的文件；已替换、已变化或无法访问的文件可能跳过。请查看处理结果，未完整还原时保留恢复记录。

需要保留还原能力期间，请保存 `%LOCALAPPDATA%\CPLUSCLEANER\`，包括 `software-migrations.jsonl` 和完整的 `compression/` 目录，并保留已搬家的实际文件。恢复记录只描述操作和文件身份，不包含软件文件内容备份，也不能恢复永久删除的文件。“操作记录 → 全部清空”只清除操作日志，不会执行还原，也不会删除独立的搬家、压缩恢复记录。

## 语言与本地数据

首次启动按 Windows 显示语言选择界面：台湾、香港及澳门的繁体显示语言使用繁体中文，其他中文变体使用简体中文，其他语言使用英文。可在“设置 → 语言”中选择“简体中文”“繁體中文”或“English”；选择会保存并立即生效，保留扫描结果和勾选状态。缺少某条翻译时使用英文。真实软件名称、文件路径及 Windows 返回的内容按对应规则保留原样。

设置、日志和恢复记录保存在：

```text
%LOCALAPPDATA%\CPLUSCLEANER\
```

清理在本地进行，不需要账号或云端服务；打开反馈链接会使用浏览器，不会自动上传诊断报告。文件操作日志可能包含本地路径。

## 绿色版的更新与移除

EXE 与 ZIP 均无需安装。设置、日志和恢复记录保存在上述 Windows 用户数据目录中，而非 EXE 旁边；单独移动 EXE 不会将这些数据转移到其他 Windows 账号或电脑。

### 更新

通过右上角 **三横菜单 → 检查更新**，将正在运行的版本与 [GitHub 最新正式 Release](https://github.com/jackqiuai/cplus-cleaner/releases/latest) 比较，发现新版本时显示提示。仅在主动点击时联网检查，检查过程不会阻塞界面；需要能够访问 GitHub，无需账号或 API key。下载后仍需按下列步骤手动替换 EXE，程序不会覆盖正在运行的文件。

1. 等待正在执行的操作完成。如果准备更换 EXE 的存放位置，请先在旧版本中关闭“设置 → 开机自启动”，并点击“保存设置”。
2. 通过程序菜单或托盘菜单中的“退出软件”完全退出。下载新版本后替换旧 EXE，或将新的便携 ZIP 解压到选定的软件目录。
3. 保留已有的 `%LOCALAPPDATA%\CPLUSCLEANER\` 和软件搬家目标目录。需要留存设置与恢复记录时，先备份数据目录，再运行新版本。如果 EXE 路径已改变，可按需在新版本中重新开启“开机自启动”。

### 移除

1. 在“设置”中关闭“开机自启动”和“定时清理”，点击“保存设置”。等待正在执行的操作完成，再通过“退出软件”完全退出。
2. 删除 CPlus Cleaner 自身的 EXE 及便携包附带文件，保留其他文件和已搬家的软件目标目录。
3. 确认不再需要设置、日志和恢复记录后，可删除 `%LOCALAPPDATA%\CPLUSCLEANER\`。如果仍需通过本程序还原受支持的操作，请先完成还原，或保留恢复数据与实际软件文件。

移除 CPlus Cleaner 不会自动撤销之前的软件搬家或压缩，也不会找回已经删除的文件。
